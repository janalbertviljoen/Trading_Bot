# Baselines and reference values

- `benchmarks/baseline.json` holds the regression baseline: the default backtest's
  metrics per frozen dataset. `regression_check` compares against it; a refactor must
  return `unchanged`.
- Hand-computed reference values in `tests/**/fixtures/` carry their derivation in a
  comment.
- Never edit a baseline, reference value or tolerance to make a check pass. A baseline
  is rewritten (`update_baseline=True`) only for an intentional methodology change, with
  the user's approval recorded in the change file.
- Reference values are never generated by the code under test and then presented as
  independent.
